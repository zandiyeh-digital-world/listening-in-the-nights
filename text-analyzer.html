To add a connection, review a verb record and name both its actor and the character affected. Use the same name for aliases. This graph includes reviewed links from the entire text.

    How the tool works

    The tool searches for selected English verbs and adjectives in simple subject and description patterns. It suggests roles from word lists and flags pronouns for context review. It cannot reliably resolve pronouns, negation, hypothetical actions, or who speaks within a quotation. Counts reflect matches and edits within these rules. The graph uses connections confirmed by the visitor.
